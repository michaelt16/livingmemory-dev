# Testing instructions for judges

Thanks for evaluating Living Memory. Here’s the fastest way to see the app with real content.

## Quick path (recommended)

1. **Open the app** (landing page).
2. Click **“Try demo”** (or use **Sign in** in the header).
3. On the profile screen, **choose any family member** (e.g. **Michael**). You’ll be taken to the album list.
4. You’ll see **7 pre-loaded demo albums** with photos, animations, and stories. Click any album to open it.
5. From an album you can:
   - Use **Editor** – timeline, media pool, narration, video export.
   - Use **Storybook** – narrated storybook view.
   - Use **Scrapbook** – polaroid-style layout.
   - Use the **EVA orb** (bottom right) to add memories with voice (Nova Sonic).

## Alternative path (full onboarding)

1. Click **“Get started”** on the landing page.
2. Watch the intro (or click **Skip**).
3. Enter a name; the family code is pre-filled as **FAMILY2024** (you can change it).
4. Click **Begin** → choose **“Let’s preserve some memories”** or **“I’ll just browse”**.
5. If you already have an account, use **“Already have an account? Sign in”** to go to the profile picker.

## What’s in the demo

- **7 albums**: Summer BBQ 2024, Christmas 2023, Family Reunion, Old Times, Beach Trip 2024, Graduation Day, Wedding Anniversary.
- **Photos and animations** are seeded; some albums have cover videos and storybook-style content.
- **Family code** for the demo family: **FAMILY2024** (pre-filled on the intro name form).

## Notes

- **Voice (EVA)** uses Amazon Nova 2 Sonic. If the connection fails, you’ll still see the UI; capture and other flows may fall back to text.
- **Animation** uses Veo 3 / Grok; seeded albums point to pre-rendered clips in `/animations/`.
- For a **private repo**, access has been shared with the hackathon testing accounts as per the rules.
